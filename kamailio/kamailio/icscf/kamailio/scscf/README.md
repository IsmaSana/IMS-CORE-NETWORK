# S-CSCF Configuration

The Serving Call Session Control Function (S-CSCF) is the central SIP control element of the IMS core.

In this deployment, the S-CSCF manages registered subscribers, handles SIP session control, and interacts with the HSS to support IMS authentication and service procedures.

**SIP listening port:** 6060 (UDP/TCP)

**Diameter connection:** PyHSS HSS

The configuration files and implementation details will be documented here.
