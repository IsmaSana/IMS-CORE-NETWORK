# Kamailio Configuration

This directory contains the configuration files and documentation related to the three Kamailio instances deployed in the IMS core:

- **P-CSCF** – Proxy Call Session Control Function
- **I-CSCF** – Interrogating Call Session Control Function
- **S-CSCF** – Serving Call Session Control Function

The three instances handle SIP signaling and interact with the HSS through the Diameter protocol.

Configuration files will be added progressively.
