# Database Configuration – MariaDB

MariaDB is used as the relational database management system in this IMS deployment.

It stores configuration and operational data required by the IMS components.

### Deployment Details

- **Component:** MariaDB
- **Database engine:** MariaDB
- **Database port:** 3306
- **Installation environment:** Ubuntu 24.04

### Databases

The deployment includes the following Kamailio databases:

- `pcscf`
- `icscf`
- `SCSCF`

These databases support the operation of the corresponding IMS components.

Database credentials and sensitive information are intentionally excluded from this repository.
